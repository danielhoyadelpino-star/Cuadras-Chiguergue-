# 🐴 Cuadras Chiguergue - Sitio Web

Sitio web profesional para el centro ecuestre Cuadras Chiguergue en Tenerife.

## ✨ Características

- 🎨 Diseño profesional con colores tierra
- 📱 Totalmente responsive (móvil, tablet, desktop)
- 📧 Formulario de contacto con EmailJS
- 🖼️ Galería con 30 fotos y filtros por categoría
- 🐴 Información de clases, caballos, excursiones, transporte y más

## 🚀 Publicación Gratuita

Este sitio está listo para publicarse **GRATIS** en:
- ✅ **Netlify** (recomendado)
- ✅ **Vercel**

**Lee el archivo `DEPLOYMENT_INSTRUCTIONS.md` para instrucciones paso a paso.**

## 📁 Estructura

```
frontend/
├── public/
│   └── images/          ← 30 fotos del centro
├── src/
│   ├── components/      ← Componentes React
│   └── data/
│       └── mock.js      ← Contenido del sitio
└── package.json
```

## 🔧 Tecnologías

- React
- TailwindCSS
- Shadcn UI
- EmailJS (formulario de contacto)
